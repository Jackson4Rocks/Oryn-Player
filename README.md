# ORYN Music Player

ORYN is a local-first Android music player built around a calm, expressive, AMOLED-friendly interface.

## Current UI prototype

- Home / Library / Playlists navigation
- Floating bottom navigation
- Liquid-glass inspired surface with translucent layers and edge highlights
- Animated active navigation capsule
- Floating mini-player above the navigation surface
- Dark AMOLED-first visual system
- Album-art-inspired color treatments
- Compose-based UI ready for the local MediaStore playback layer

## Build

Open the project in Android Studio and use the installed Android SDK / current Android Gradle tooling.

The project targets Android 26+ and uses Jetpack Compose with Material 3.
